# Лабораторна робота №2. Протокол ARP

**Злотко Олексій, ІК-34**  
Дисципліна: Тестування та контроль якості (QA) вбудованих систем  
Варіант: **2** (останні цифри залікової книжки — 08, 8 % 3 = 2)

## Що робив

Працював в Ubuntu (WSL2) на Windows 11. Спочатку перевірив IP-адресу, маршрут за замовчуванням і таблицю сусідів. Потім записав ARP- та ICMP-пакети через `tcpdump` і переглянув їх у Wireshark.

## Результати

- Адреса комп’ютера в WSL2: `172.22.174.249`.
- Шлюз: `172.22.160.1`.
- У захопленому трафіку є ARP Request від шлюзу та ARP Reply від комп’ютера. Комп’ютер повідомляє MAC-адресу `00:15:5d:9d:e0:ec`.
- У файлі захоплено 8 пакетів, з них 4 — ICMP Echo Request. Echo Reply у цьому файлі немає.
- Після перевірки в ARP-кеші залишився запис шлюзу `172.22.160.1 → 00:15:5d:06:df:d8`, стан `STALE`.

Для свого варіанта склав [тест-кейс TC-ARP-03](TC-ARP-03.md): перевірка статичного запису IP–MAC. У практичній частині досліджував звичайний ARP-обмін; окремо статичний запис не додавав.
